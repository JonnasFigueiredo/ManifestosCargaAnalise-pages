# ManifestosCargaAnalise Pages

Demo estática do painel TSC Express, com métricas agregadas de importação do Comex Stat e uma aba de análise de clientes. O site não executa o backend Flask nem inclui o banco SQLite ou os relatórios locais.

Os dados expostos nesta demo são públicos e podem ser consultados sem senha. GitHub Pages não fornece autenticação por usuário e senha.

Para atualizar os arquivos estáticos, gere um novo retrato no projeto de origem e atualize a pasta `site/` deste repositório.
